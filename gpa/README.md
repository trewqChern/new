# Bangladesh Education Board HSC Result Page

A pixel-perfect, responsive HTML & CSS implementation of the Bangladesh Intermediate and Secondary Education Boards HSC/Alim Result sheet.

## Files

- [**`index.html`**](file:///c:/Users/USER/Downloads/GoogleChromePortable/NewDownloads/new/gpa/index.html): The main HTML file containing the document structure, tables, and embedded high-resolution SVG emblems (Bangladesh Govt Emblem & Teletalk logo).
- [**`style.css`**](file:///c:/Users/USER/Downloads/GoogleChromePortable/NewDownloads/new/gpa/style.css): The complete stylesheet including layout, typography, colors, table stripes, and print styles.

## Usage

1. Open `index.html` directly in any web browser (Chrome, Edge, Firefox).
2. The page is completely self-contained with vector graphics, requiring no internet connection or external image assets.
3. Use your browser's Print dialog (`Ctrl + P`) to view or save a clean printable PDF version.
